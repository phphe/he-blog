---
title: "Not Recommended to Use Git LFS for Website Projects"
date: "2025-07-14 16:22"
tags: ["git", "tool", "git-lfs"]
---

- Website projects like React, Next, Vue, Nuxt typically contain some image files (e.g. logos), but usually not too many.
- After using Git LFS, you may find corrupted images when only using `git clone` to pull the project to server.
- Although you can try commands like `git lfs pull` to fix, server operations are less convenient than local.
- When deploying my Nuxt website to server, I encountered corrupted images. After using `git lfs pull`, the PNG files existed on server but showed completely transparent empty images when accessed via URL.
- Avoiding Git LFS will save your time and effort.
