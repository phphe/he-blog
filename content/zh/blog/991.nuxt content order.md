nuxt content 模块支持通过给 markdown 文件名添加数字前缀以排序. 例如:

- 1.about.md
- 2.contact.md
- 3.services.md

但是通过该模块的 api 取出的数据也是这样的顺序, 而我们习惯最新数据显示在上面. 所以我的解决方法是数字前缀从大到小使用.

- 997.services.md
- 998.contact.md
- 999.about.md
